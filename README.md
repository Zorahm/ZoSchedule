# ZoSchedule

Telegram-бот расписания учебной группы МТИ.

Сайт колледжа показывает только текущее состояние расписания: что пару
перенесли, отменили или сменили преподавателя, там не видно. ZoSchedule
сохраняет каждый прогон парсера целиком как снимок, сравнивает снимки и сообщает
о разнице в Telegram-группу: картинками недели и дня и текстом об изменениях.

## Что где

```
parser.py            парсер сайта — внешний контракт, не редактируется
config.toml          группа, интервал опроса, время постов
.env.example         шаблон секретов (токен бота) для .env
backend/             Python: парсер-обёртка, снимки, дифф, SQLite
backend/app/bot/     Telegram-бот: картинки недели и дня, тексты изменений
start-bot.bat        запуск и первичная настройка на Windows
install.sh           установка с автозапуском на Linux (systemd)
AGENTS.md            стандарты проекта
```

## Настройка

Всё, что нужно поменять под себя, — в [config.toml](config.toml):

```toml
[group]
name = "ОККИПд-307"   # ровно как на сайте колледжа

[poll]
interval_minutes = 60 # как часто бот опрашивает сайт

[bot]
today_at = "07:00"    # «Сегодня» каждое утро, МСК
day_ahead = false     # true: завтрашний день приходит, как только кончились пары
week_at = "07:00"     # неделя в воскресенье, МСК
silent = false        # true: все сообщения бота приходят без звука
theme = "auto"        # "auto": ночная тема с 20:00 до 07:00 по Москве; или "light" / "night"
night_from = "20:00"  # начало ночи, МСК
night_to = "07:00"    # конец ночи, МСК
```

Секреты в `config.toml` не пишутся: токен бота и остальное лежат в `.env`
(см. ниже) или в переменных окружения.

## Запуск

**Windows:** дважды щёлкните [start-bot.bat](start-bot.bat) (или запустите из консоли).
Первый запуск сам найдёт Python 3.11+, создаст окружение `.venv`, поставит
зависимости, проверит браузер для картинок (Chrome/Edge, иначе поставит Chromium) и
спросит токен бота (ввод скрыт, токен проверяется в Telegram и пишется в `.env`).
Дальше он запускает бота и перезапускает, если тот упал.

```bat
start-bot.bat           :: подготовить (если нужно) и запустить
start-bot.bat setup     :: только подготовить окружение
start-bot.bat token     :: задать токен заново
```

**Linux:** [install.sh](install.sh) ставит всё и настраивает автозапуск через systemd.

```bash
chmod +x install.sh && ./install.sh     # без root: sudo скрипт спросит сам
./install.sh status | logs | restart | token | uninstall
```

Скрипт создаст `.venv`, поставит зависимости и Chromium (Playwright, с системными
библиотеками на apt-дистрибутивах), спросит токен, группу и время постов (Enter —
оставить), запишет `.env` (права 600) и создаст службу `zoschedule-bot`, которая стартует
вместе с системой и перезапускается при сбое. Пошаговая инструкция для VDS (сервер,
доступ к репозиторию, прокси, обновление, бэкап): [docs/vds.md](docs/vds.md).

**Вручную:**

```bash
cd backend && pip install -e ".[dev]"
python -m app.bot run
```

Один процесс делает всё: слушает команду `/go`, сам опрашивает сайт, шлёт и
обновляет картинки. Переменные окружения (или `.env`): `ZOSCHEDULE_BOT_TOKEN`,
`ZOSCHEDULE_CONFIG` (путь к конфигу), `ZOSCHEDULE_DB` (путь к базе).

## Telegram-бот

Бот сам присылает в группу расписание и сообщает об изменениях.

| Что | Когда | Как |
|---|---|---|
| **Неделя** (Пн–Сб, картинка) | воскресенье, `week_at` | закрепляется; старая неделя открепляется и удаляется |
| **Сегодня** (картинка) | каждый день, `today_at` (07:00 МСК) | вчерашнее «Сегодня» и тексты изменений удаляются |
| **Завтра** (картинка, при `day_ahead = true`) | накануне, сразу после последней пары; в день без пар в `today_at` | заменяет «Сегодня»: картинка дня удаляется; в полночь подпись сама меняется на «Сегодня»; утреннего поста нет |
| **Изменения** | сразу после прогона, нашедшего разницу | отдельное текстовое сообщение (оно даёт пуш), только про текущую неделю |

Картинки показывают только актуальное расписание, без пометок об изменениях. На неделе у каждой пары
после названия стоит цветная точка типа (лекция синяя, практика и лабораторная зелёные,
экзамен и зачёт красные — те же цвета, что у плашек на картинке дня), внизу легенда
только по типам этой недели; у выходных блок дня недели залит зелёным (`#228B22`).
В полоске дней наверху картинки дня выходные тоже зелёные (текущий день остаётся
оранжевым). День, который ещё не опубликован, зелёным не выделяется. Если пары на них
перестали совпадать со свежим снимком (изменение, или день опубликовали позже),
картинка **редактируется на месте** (`editMessageMedia`), закреп остаётся.
Сравнение идёт по итоговой вёрстке картинки, а не по событиям диффа: дифф не видит
дни, опубликованные позже воскресной картинки.

### Подключение

1. Создайте бота у @BotFather, добавьте его в группу и сделайте администратором с
   правами «удалять сообщения» и «закреплять сообщения». Без них бот работает,
   но старое не удаляет и неделю не закрепляет (пишет предупреждение в лог).
2. Токен положите в `.env` (шаблон — [.env.example](.env.example)). Там же
   впишите **доверенных**: `ZOSCHEDULE_BOT_TRUSTED_USERS=123456789` (Telegram-id
   людей через запятую; свой id покажет @userinfobot) или `trusted_users` в
   `config.toml`.
3. Запустите `python -m app.bot run`, и доверенный пользователь пишет **`/go`** в
   группе (в нужной теме, если группа с темами). Бот запомнит чат, сразу пришлёт
   неделю и ближайший день, дальше всё по расписанию.

**Доступ.** Бот слушается только людей из `trusted_users`: остальным он не отвечает
вовсе (их id попадает в журнал, чтобы вы могли добавить нужного). Групп может быть
несколько: `/go` доверенного в каждой добавляет её к уже работающим, расписание у всех
одно, а сообщения у каждой свои (неделя, «Сегодня», изменения, закреп). `/stop`
доверенного в группе перестаёт слать туда (бот остаётся участником, прежние посты
остаются); если бота удалили из группы, он сам забывает её. Сбой в одной группе
(бота кикнули, Telegram не принял) не мешает остальным. Если бота добавил в
группу недоверенный человек, бот сам выходит из неё; если доверенный, остаётся и
ждёт `/go`. Группы из белого списка `trusted_chats` (id через запятую, у групп они
отрицательные; `ZOSCHEDULE_BOT_TRUSTED_CHATS` в `.env` приоритетнее) бот не покидает,
кто бы его ни добавил; команды и в них принимает только `trusted_users`. Id группы
пишется в журнал, когда бот из неё выходит. Список доверенных пуст: `/go` не примет
никто, и бот выйдет из любой новой группы вне белого списка (предупреждение об этом
есть в журнале при запуске). Из групп, где бот уже состоял
до включения этой защиты, он сам не выходит: уберите его оттуда вручную.

Для картинок нужен браузер: подойдёт установленный Chrome или Edge, иначе
`playwright install chromium`. Свой путь — `bot.browser_path` в конфиге.

### Секреты в `.env`

Скопируйте [.env.example](.env.example) в `.env` (в git он не попадает) и впишите
токен бота. Настоящие переменные окружения приоритетнее файла, пустые строки
игнорируются. Чат в `.env` обычно не нужен: его запоминает `/go`. Другой путь к
файлу: `ZOSCHEDULE_ENV_FILE`.

Необязательно: `ZOSCHEDULE_BOT_PROXY=socks5://[логин:пароль@]хост:порт` (также
`socks4://`, `http://`, `https://`) пускает через прокси все запросы бота к Telegram,
если `api.telegram.org` напрямую недоступен. Сайт колледжа парсер открывает без
прокси. Значение считается секретом: в лог попадают только схема, хост и порт, а
неверный формат сообщает подсказку, не показывая строку. Без переменной всё работает
как раньше. `start-bot.bat` проверяет токен напрямую, мимо прокси: за блокировкой
впишите токен в `.env` вручную.

### Проверка на тестовой базе и тестовой группе

```bat
set ZOSCHEDULE_DB=D:\scratch\test.db
set ZOSCHEDULE_BOT_TOKEN=...
set ZOSCHEDULE_BOT_CHAT_ID=...
cd backend
python -m app.bot seed-demo       :: демо-расписание в пустую базу (в настоящую не пишет)
python -m app.bot preview         :: картинки в папку bot-preview, без Telegram
python -m app.bot post-week       :: отправить неделю сейчас (закрепит)
python -m app.bot post-today      :: отправить «Сегодня» сейчас
python -m app.bot demo-change     :: новый снимок: перенос, смена препода, отмена, добавление
python -m app.bot announce        :: объявить эти изменения текстом
python -m app.bot sync            :: перерисовать устаревшие картинки на месте
python -m app.bot simulate        :: неделя жизни бота с подставными часами (живой чат!)
python -m app.bot run             :: рабочий цикл (раз в минуту)
```

`post-week` и `post-today` принимают `--force`, чтобы отправить повторно.
`simulate` работает только на пустой тестовой базе: воскресенье → понедельник →
изменение → вторник → следующее воскресенье, с настоящими сообщениями в чате.

**Снимки бот обновляет сам**: на каждом такте по интервалу `poll.interval_minutes`,
а перед первой отправкой недели (воскресенье) и «Сегодня» (утро) принудительно.
Ручные команды тоже сначала берут свежий снимок. На демо-базе это надо выключить:
`python -m app.bot --no-refresh post-week` (флаг стоит **перед** командой), иначе
демо-данные заменятся ответом настоящего сайта. Совсем отключить опрос ботом
можно через `[bot] refresh = false`.

При закреплении Telegram сам пишет в группу служебное «бот закрепил сообщение».
Бот получает его через обновления Telegram и удаляет, но только если оно написано
им самим (закрепы людей не трогает). Учёт бота тут не проверяется: картинку могли
закрепить другим процессом (симулятор, ручной `post-week`) или уже забыть в учёте.
Сбой при удалении повторяется до трёх раз. Нужно право «Удалять сообщения».
Обновления Telegram хранит сутки: уведомления от закрепов, сделанных пока бот не
слушал (симулятор, ручные команды), бот уберёт при следующем запуске, но не позже.

Фото Telegram пережимает до 1280 px, поэтому шрифты на картинках крупные.

## Известные ограничения

- **Деления на подгруппы нет.** Единственное отличие пары для группы —
  поточная лекция: чужие группы из `groups[]` попадают в `stream`
  («гр. 306» и легенда на картинке дня).
- **Группа из конфига может отсутствовать в списке сайта.** Список групп
  меняется между семестрами. Если группы нет и расписание пустое, прогон
  считается неудачным, бот пишет об этом в лог и шлёт по последнему снимку.
- **Номер пары на картинке вычисляется** по порядку занятий внутри дня: сайт
  номера не отдаёт.
- **Старые таблицы «Вариантов»** (`students`, `variants`, `variant_topics`) в уже
  существующей базе остались нетронутыми, но код к ним удалён.
